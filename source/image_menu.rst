.. _image_menu:

======================
All Image Menu Options
======================

The image menu provides options for editing the properties of the current
session, modifying visualization, generating overlays, and viewing interactive 3D
renders.

.. contents:: On this page
   :local:
   :depth: 2


Image → Properties
------------------

The properties menu displays which properties are currently present, and is where
xy_scale and z_scale should be set.

1. **xy_scale** — a float corresponding to the pixel-to-real-world distance of
   your image. This does not auto-populate when loading images and must be
   entered here, or in functions that request it. NetTracer3D presumes x and y
   scales are always equal, and therefore does not support images transformed
   along only a single 2D axis.
2. **z_scale** — a float corresponding to the voxel-to-real-world depth or step
   size of your image. This likewise does not auto-populate and must be entered
   here or where requested.
3. **Nodes status** — enabled when something is loaded into the nodes channel.
   Disabling it and entering the new properties empties the nodes channel and
   purges the ``node_identities`` and ``node_centroids`` properties.
4. **Edges status** — enabled when something is loaded into the edges channel.
   Disabling it and entering the new properties empties the edges channel and
   purges the ``edge_centroids`` property.
5. **Overlay1 status** — enabled when something is loaded into the Overlay1
   channel. Disabling it and entering the new properties empties that channel.
6. **Overlay2 status** — enabled when something is loaded into the Overlay2
   channel. Disabling it and entering the new properties empties that channel.
7. **Node Search Region status** — enabled when something is loaded into the
   hidden search regions property. Disabling it and entering the new properties
   purges that property.

   This property is generated by the connectivity network function and represents
   the search space of expanded nodes. It is saved with Network3D objects but
   cannot currently be loaded directly back into this property. It can, however,
   be loaded into the nodes property in order to run the connectivity network
   again while skipping the node search expansion step, which is the slow step.
8. **Network status** — enabled when something is loaded into the network
   property or table. Disabling it and entering the new properties empties the
   network and purges the communities property.
9. **Identities status** — checked when the node identities property is set.
10. **Enter (Erases Unchecked Properties)** — accepts reassigned properties,
    principally the xy and z scales if altered, and purges anything left
    unchecked from the current session.
11. **Report Properties** — populates the upper right table with any property
    associated with a spreadsheet that exists in the current session.

.. note::

   For statuses 3–7, enabling a button that was previously disabled has no
   effect; this menu is not for loading.


Image → Adjust Brightness/Contrast
----------------------------------

Opens a menu for altering the brightness and contrast of each image. Every
channel has a dual-knobbed slider alongside minimum and maximum values: move the
left knob or enter a value of 0–65534 in the left bar to set the maximum
brightness, and move the right knob or enter a value of 1–65535 to set the
minimum. If a loaded image is not visible, use this menu to reveal it.


Image → Channel Colors
----------------------

The default channel colors are light red for nodes, light green for edges, and
white for Overlay1 and Overlay2. These can be changed here from a wide selection
of preset colors.


Image → Overlays → Create Network Overlay
-----------------------------------------

Where a network is present with node centroids — you are prompted if none exist —
this draws 1-voxel-thick white lines between all node centroids. The overlay is
placed in Overlay1 and provides a convenient way to visualize network structure,
particularly in 3D.

The lines are thin by default, so for larger images dilating the overlay slightly
may improve visibility. An optional downsample parameter enlarges the rendered
output by the magnitude of the entered value.


Image → Overlays → Create ID Overlay
------------------------------------

Where a network is present with node centroids — you are prompted if none exist —
this writes the numerical ID of each node over its centroid. The overlay is
placed in Overlay2 and provides a convenient way to visualize node labels. An
optional downsample parameter enlarges the rendered output by the magnitude of
the entered value.


Image → Overlays → Color Nodes (or Edges)
-----------------------------------------

Creates an RGB overlay in which each grayscale label in the nodes or edges image
is assigned a unique color. The overlay is placed in Overlay2, and a legend
mapping each node or edge to its color is placed in the tabulated data widget.
This is an excellent way to visualize which nodes and edges have been labeled.

1. A dropdown selecting whether to color the nodes or the edges.
2. A dropdown selecting the default, alternate, colorblind, custom, or previous color scheme.
3. ``down_factor`` — applies an internal downsample equivalent to the entered
   integer across all three dimensions before drawing the overlay. This speeds up
   processing, but over-downsampling small nodes may remove them from the image.


Image → Overlays → Shuffle
--------------------------

Swaps the data held in two channels. Select the channels to swap from the
dropdown menu and their images are exchanged; if one channel is empty, the data
from the other is moved into it.

This is particularly useful in practice, since NetTracer3D often writes outputs
to specific overlay channels — overwriting any preexisting data there — and
expects contents in certain channels for other functions. Branch labeling, for
example, must be done in the edges channel, while grouping branches into networks
must be done in the nodes channel. Shuffle moves each to the correct channel
without saving and reloading images. You can also use duplicate to copy one channel into another without
altering the original channel.


Image → Select Objects
----------------------

Selects arbitrary groups of objects and locates them in the image.

Parameter explanations
~~~~~~~~~~~~~~~~~~~~~~

1. **Type to Select** — whether to select objects in the nodes or edges channel.
2. **Select the following?** — enter a list of unspaced integers separated by
   commas (for example ``4,5,7,10``) to select and highlight them. NetTracer3D
   also navigates to the Z-plane of the node corresponding to the first integer,
   so this window doubles as an arbitrary search for nodes and edges.

   **Import Selection from spreadsheet...** opens a file browser; selecting a
   ``.csv`` or ``.xlsx`` file with the integers of the desired objects in the
   first column auto-populates this parameter, allowing groups of objects
   pre-organized by other means to be selected.
3. **Deselect the following?** — enter a list of unspaced integers separated by
   commas to deselect them, if they were selected. **Import Selection from
   spreadsheet...** works as above, for deselection.

   Parameter 2 always overrides parameter 3, so selecting and deselecting the
   same object results in it being selected.


Image → Show 3D (Napari)
------------------------

Renders all visible images in 3D using Napari, the premiere open-source Python 3D
image viewer: Chi-Li Chiu, Nathan Clack, the napari community, napari: a Python
Multi-Dimensional Image Viewer Platform for the Research Community, Microscopy
and Microanalysis, Volume 28, Issue S1, 1 August 2022, Pages 1576–1577,
https://doi.org/10.1017/S1431927622006328

Napari shows any channels currently visible in the bottom control panel, so
disable the visibility of any channels you do not wish to show. The highlight
overlay is also shown if present. This requires Napari to be installed in
NetTracer3D's package environment.

If your monitor is connected to your GPU, Napari uses it for rendering by
default, and displays are smooth as long as the total size of your images is less
than your available VRAM. This visualization does not use image pyramids, so
images exceeding your card's VRAM should be downsampled to avoid lag. If your
monitor is not using the GPU, this visualization is limited to small images.

The Napari 3D window is interactive like the main image viewer window. Press
:kbd:`S` to toggle selection mode, in which 3D objects can be clicked to select
them, with full access to the main viewer window's right click functions.

Parameter explanations
~~~~~~~~~~~~~~~~~~~~~~

#. **Downsample Factor** — temporarily downsamples the image in all three
   dimensions by the entered factor to speed up the 3D display.
#. **Use cubic downsample?** — uses the cubic resample algorithm, which is slower
   but may better preserve shapes.
#. **Include Bounding Box** — draws a bounding box around your channels. The
   bounding box is an array of equivalent size to the other channels and will
   demand the corresponding RAM.
#. **Node Rendering** — nodes are rendered in a single color by default. Set this
   to **Label Render** to use Napari's label render system, which assigns a
   unique color to every node.
#. **Edge Rendering** — edges are rendered in a single color by default. Set this
   to **Label Render** to assign a unique color to every edge.

Press **Show 3D** to create the display with the chosen parameters. A new Napari
window opens showing the selected channels. Any RGB images are split into
separate red, green, and blue channels.
